## Question

Finalize the 5-Class amoeba roster, spanning smaller-than-player to bigger-than-player. For each Class define:

- Relative size tier.
- Movement/behavior personality — the krill archetype is the template already established: schools up over time, flees immediately on detecting a whale-Class Amoeba.
- Threat/utility role (prey, Ammo/Food source, predator, obstacle, etc.).
- The abstracted-but-recognizable real-animal analog it should evoke — krill and whale are already named as two of the five; what are the other three, and do they map to any of the two signature levels' needs?

## Notes

The whale Class is modeled on Bursaria truncatella (bag-shaped ciliate with a deep oral funnel that swallows prey whole) — see map Decisions so far. The other four Classes still need their own real-organism silhouette references.

Coral larvae are a candidate Class example for the "same creature, terror now / food later" principle (see map): clustered on a shaft that looks like a static grape vine, then dislodge and swarm the player. Consider which Class tier they sit in and how a Class reads differently as the player outgrows it.
